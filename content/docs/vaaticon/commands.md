### /server <server-name>
🔑 Permission : `vaaticon.server.<server-name>`
💡 Send the player to the desired server if version and online status matches.

### /send <player> <server-name>
🔑 Permission : `vaaticon.send`
💡 Send the desired player to the desired server if version and online status matches.

### /vaaticon version
🔑 Permission : `vaaticon.admin`
💡 Send the player to the desire server if version and online status matches.

### /vaaticon ownversion
🔑 Permission : `vaaticon.admin`
💡 Show the player's protocol number

### /vaaticon serverversion
🔑 Permission : `vaaticon.admin`
💡 Show the server's accepted protocols

### /vaaticon selfcheck
🔑 Permission : `vaaticon.admin`
💡 Show a ddebug version selfcheck
